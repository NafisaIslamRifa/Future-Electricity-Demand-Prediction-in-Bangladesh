# Future Electricity Demand Prediction in Bangladesh

This project focuses on forecasting future electricity demand in Bangladesh using time series analysis and machine learning techniques. Accurate demand prediction helps in power generation planning and energy management.

## Objectives
- Predict future electricity demand
- Analyze historical electricity consumption trends
- Support energy planning decisions

## Dataset
- Bangladesh electricity demand data
- Source: PGCB / public energy datasets
- Time-series structured data

## Methodology
- Data preprocessing
- Time series visualization
- Feature engineering
- Model training and evaluation

## Models Used
- Linear Regression
- Random Forest
- LSTM (optional)
- ARIMA (optional)

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Results
The model successfully predicts future electricity demand trends based on historical consumption patterns.
